# Tò Mò Kids pilot

This preset is a deliberately small end-to-end Vietnamese test for the MoneyPrinterTurbo fork.

It verifies:

- prepared Vietnamese script (no LLM/API key required)
- local 16:9 materials generated by FFmpeg
- Edge TTS Vietnamese narration using `vi-VN-HoaiMyNeural`
- subtitles generated from the TTS timing data
- no background music, so narration quality is easy to judge
- final MP4 rendering through the normal MoneyPrinterTurbo pipeline

## Run locally

Requirements: Python 3.11+, `uv`, and FFmpeg.

```bash
uv sync --frozen
bash presets/tomo-kids/run-pilot.sh
```

The generated task is written under `storage/tasks/<task-id>/`.

## Why the visuals are simple

The three local scene clips are generated automatically from flat colors and geometric shapes. The purpose of this first pilot is to isolate and evaluate Vietnamese TTS, subtitle timing, and the production pipeline. Once narration is approved, replace these clips with the real Tò Mò Kids mascot/background asset library without changing the voice or rendering workflow.
